\# ❤️ Heart Disease Prediction



\## 📌 Project Overview



This project predicts the possibility of heart disease using Machine Learning.



The project includes a trained Machine Learning model and a Streamlit web application where users can enter patient information and receive a prediction.



\## 🤖 Machine Learning



The project uses a trained Machine Learning model to make predictions based on heart-related features.



\### Main steps:

\- Data loading

\- Data preprocessing

\- Feature selection

\- Feature scaling

\- Model training

\- Model evaluation

\- Prediction



\## 🛠️ Technologies Used



\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- Joblib

\- Streamlit

\- Jupyter Notebook
